# Cosmic Carrot Lottery — Космический генератор лотерейных чисел (TRNG)

Браузерный генератор истинно случайных чисел (TRNG) без внешних зависимостей для составления лотерейных комбинаций (**7 из 35 + 1 из 54**), оформленный в весёлом стиле с зайцем и морковками. Приложение в реальном времени собирает телеметрию из пяти открытых космических источников (солнечный ветер, межпланетное магнитное поле, рентгеновское излучение Солнца, потоки космических протонов и орбитальные данные МКС) и смешивает её с локальной аппаратной энтропией для получения несмещённых случайных чисел.

---

## Основные возможности

* **Гибридный пул энтропии (`Space + 16 B CSPRNG + 16 B Jitter`):** Скрипт парсит 100% доступных числовых показаний спутников без обрезания массивов, извлекает по два младших байта мантиссы (`LSB`) из каждого замера `Float64` и объединяет их со 128 битами аппаратного генератора браузера (`crypto.getRandomValues`) и 128 битами микросекундного джиттера таймера/процессора (`performance.now()`).
* **Честная генерация без смещения (Rejection Sampling):** Использует криптографический потоковый генератор на базе **SHA-256** в режиме счётчика с отбрасыванием значений выше кратного порога (`limit = Math.floor(2^32 / N) * N`). Это полностью исключает статистический перекос (modulo bias) в обоих игровых полях:
  * **Поле 1 (`1–35`):** Выбирает **7 уникальных, неповторяющихся чисел**, сортирует их по возрастанию и отображает в виде объёмных **жёлтых лотерейных шаров**.
  * **Поле 2 (`1–54`):** Выбирает **1 дополнительное число** независимо от первого поля (совпадения с числами из Поля 1 разрешены) и отображает его в виде объёмного **розового лотерейного шара**.
* **Локальная работа в браузере:** Все сетевые запросы к орбитальным API, извлечение младших бит, хеширование SHA-256 и отбор чисел выполняются исключительно на стороне клиента без промежуточных серверов.
* **Дизайн в стиле зайца и морковок:** Бесшовный SVG-фон с морковками, тёплая морковно-оранжевая палитра, анимация появления 3D-шаров и кнопка быстрого копирования комбинации в буфер обмена.
* **Двуязычный интерфейс (`RU` / `EN`):** Мгновенное переключение между русским и английским языками без перезагрузки страницы.

## Запуск и развёртывание

### Локальный запуск

```bash
# С помощью Python 3
python -m http.server 8000
```

После этого откройте `http://localhost:8000` в браузере и нажмите кнопку **«🐰 Сгенерировать числа»**.

## Криптографический конвейер

1. **Сбор телеметрии:** Параллельный опрос выбранных эндпоинтов NOAA SWPC и МКС с автоматическим переключением на резервные зеркала и таймаутом `8000 мс`.
2. **Извлечение хаоса (LSB):** Перевод 100% числовых замеров в буфер стандарта IEEE-754 `Float64` и извлечение двух младших байт мантиссы каждого числа с отсеиванием предсказуемых макрозначений.
3. **Формирование гибридного пула:** Склейка массива космических байт с 16 байтами из `crypto.getRandomValues` и 16 байтами микросекундного джиттера цикла CPU (`Space + 16 B CSPRNG + 16 B Jitter`).
4. **Несмещённый выбор чисел:** Подача гибридного пула в потоковый генератор SHA-256 и отбор 7 уникальных чисел из диапазона `1–35` и 1 бонусного числа из диапазона `1–54` методом отбрасывания (rejection sampling).
